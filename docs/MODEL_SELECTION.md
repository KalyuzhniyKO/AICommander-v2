# Какую модель и уровень рассуждения выбирать для задач Codex

[English](MODEL_SELECTION.en.md)

## Базовые рекомендации

| Категория | Модель для Codex (если доступна) | Усилие | Когда выбирать |
|---|---|---|---|
| Простое описание/мелкая правка | GPT-6 Luna | Low | Неизменяемый шаблон, механический перенос, простое редактирование |
| Обычная разработка / интеграции | **GPT-6.1 Sol** | **Medium** | Большинство Issues: баланс скорости, точности и затрат |
| Сложная архитектура / диагностика | GPT-6.1 Sol | High | Неочевидные зависимости, проектирование |
| Безопасность / сложный оркестратор / большой E2E | **GPT-6 Astra** | **High** | Высокая цена ошибки, взаимодействие нескольких сред |

Документация: [OpenAI model selection](https://developers.openai.com/api/docs/guides/model-selection), [reasoning effort](https://developers.openai.com/api/docs/guides/reasoning), [code generation](https://developers.openai.com/api/docs/guides/code-generation).

## Важные различия
1. **Модель Codex для выполнения Issue**: сколько размышлений тратить на разработку именно AICommander 3.0. Это таблица в ROADMAP.
2. **Модели будущих AI-ролей через OmniRouter**: free-first маршруты и fallback; реальные model IDs выбираются после проверки имеющегося сервиса. **Не подставлять автоматически GPT-6 Astra во все роли.**
3. **ChatGPT Web**: ручная платная подписка пользователя для сложного обсуждения, не API и не инструмент автоматического парсинга ответов.
4. **Codex CLI**: реальные действия в разрешённом workspace через доступные авторизованные модели, их список зависит от версии/плана.

Правило: начать с **Medium**, повышать до **High** по фактической сложности, а не по привычке. Модели, не отображаемые в конкретном меню, не считать доступными. При невозможности выполнить действие через подключённый GitHub — создавать отдельную Issue с чётким DoD и ссылкой на английскую версию.

## Порядок
Запускать очередную Issue только после проверки результата предыдущей. Если задача требует доступа к Zorin и это нельзя сделать из GitHub, Codex должен выполнить её из изолированного окружения на Zorin с твоим разрешением, а не угадывать конфигурацию.
